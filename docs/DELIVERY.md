# APK по архитектурам и загрузка моделей

В версии 0.1.6 (versionCode 7) вместо одного APK 78,30 МБ выпускаются четыре
самостоятельных установочных файла. Каждый содержит одну архитектуру и прежний
набор функций. Установка нескольких файлов или split-установщик не нужны.

| ABI | Размер APK, байт | Размер, МБ | Сокращение относительно APK 0.1.4 |
| --- | ---: | ---: | ---: |
| arm64-v8a | 30 608 447 | 30,61 | 60,9% |
| armeabi-v7a | 25 852 997 | 25,85 | 67,0% |
| x86 | 31 505 453 | 31,51 | 59,8% |
| x86_64 | 31 624 246 | 31,62 | 59,6% |

Это ещё отладочные сборки восстановленного проекта Apktool. Release-оптимизация
через R8 не выполнялась. Помимо удаления лишних архитектур размер отличается
из-за повторной упаковки Apktool.

Установочные файлы размещены в ветке `android-builds`, в каталоге
`releases/0.1.6`. README и описание выпуска `android-7` содержат прямые ссылки,
закреплённые за commit сборок. Контрольные суммы и отчёт находятся рядом с APK.

## Что докачивается

Модели греческого и русского языка отсутствуют в APK и скачиваются через
`Translator.downloadModelIfNeeded()` после явного действия пользователя.
Этот механизм существовал в 0.1.4 и сохранён; в 0.1.5 уточнены названия кнопок,
пояснения, сообщения об успехе и ошибке.

- При запуске приложения автоматическая загрузка моделей не включается.
- По кнопке загружаются только отсутствующие модели; повторная загрузка уже
  установленных моделей не требуется.
- Чтение книги, личный словарь и готовый литературный контекст доступны без моделей.
- Во время загрузки можно закрыть карточку и продолжить чтение.
- После загрузки автоматический перевод выполняется на телефоне без интернета.
- Существующее согласие на машинный перевод и настройки пользователя сохраняются.

Встроенные книжные данные не менялись; новые тексты не добавлялись.
Книга вместе с переводом, словоформами и обложкой занимает менее 1 МБ внутри APK,
поэтому она остаётся доступной офлайн сразу после установки.

В каждый APK входит нативная библиотека переводчика только для выбранной ABI.
Она устанавливается вместе с приложением. Загрузка исполняемой библиотеки
самостоятельным загрузчиком не реализована: это не штатный механизм ML Kit Translate.
Здесь используется обычный способ распространения отдельных APK через GitHub.

## Как работает сборка

1. Проверяются книжные данные и согласованность версий в `release.json`,
   `apktool.yml` и `BuildConfig`.
2. Apktool принудительно пересобирает ресурсы и smali. Это предотвращает
   использование старого скомпилированного манифеста после изменения версии.
3. Из промежуточного APK создаются варианты с одной ABI. Содержимое остальных
   ZIP-элементов сравнивается побайтово с промежуточной сборкой.
4. Проверяются ELF-заголовки всех нативных библиотек и наличие переводчика.
5. Каждый APK выравнивается на 16 КиБ, подписывается прежним ключом и проверяется
   через `apksigner`, `zipalign` и `aapt`.
6. Готовые APK, контрольные суммы и отчёты помещаются в `dist/`.

В отчёте каждого варианта есть ABI, размер, SHA-256, сертификат, хеши нативных
библиотек и результат проверки подписи. Ключ подписи не входит в Git и выпуск.

Для подписи в текущей облачной среде:

```sh
python3 scripts/project.py build-all \
  --apk /workspace/work/recovery/GreekReadingApp.apk \
  --apktool /workspace/work/recovery/tools/apktool.jar \
  --sdk /workspace/.greek-tools/android-sdk \
  --keystore /workspace/.greek-tools/android-user/debug.keystore
```

Пути среды не нужны при обычной сборке из репозитория: исходный APK и Apktool
загружаются по закреплённым адресам с проверкой SHA-256. Android SDK и прежний
ключ подписи пользователь указывает со своего компьютера.

## Проверка на Android

На программном эмуляторе Android 9 / API 28 / x86 проверены установка поверх
существующего приложения, сохранение позиции чтения, открытие книги без моделей,
компактная карточка с переводом, раскрытие вверх и сворачивание вниз,
выбор другого слова, закрытие касанием вне карточки и литературный перевод
при отключённых Wi-Fi и мобильных данных. Сохранение слова подтверждено запросом
к базе: греческое слово и русский перевод записаны корректно.

Для проверки отображения успешного перевода заранее заполнен только кэш
эмулятора. Эти тестовые данные не входят в APK. Полное скачивание моделей через
интернет и запуск на физических ARM-устройствах не выполнялись. Код загрузки
ML Kit не менялся. Все четыре APK прошли проверки подписи, состава, ELF и
выравнивания. Подробный отчёт — `docs/releases/0.1.6.json`.
