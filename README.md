# Греческая читалка

Текущая сборка **0.1.6 / versionCode 7** выпускается отдельными APK для каждой
архитектуры. Языковые модели перевода докачиваются по кнопке; книгу и литературный
русский перевод можно читать без загрузки моделей.

Карточка слова открывается в компактном виде: только перевод. Потяните её вверх,
чтобы открыть дополнительные действия. Исходное греческое предложение остаётся
в книге. [Описание и снимки экрана](docs/COMPACT_TRANSLATION.md).

Для большинства современных телефонов подходит ARM64. Если телефон использует
32-битный Android, выбирайте ARM32. Размеры указаны в десятичных МБ.
Все варианты подписаны прежним ключом и обновляют совместимую установку 0.1.4 или 0.1.5

Для включения автоматического перевода разверните карточку слова движением вверх
и нажмите «Скачать модели»; эта кнопка также есть в настройках. Потребуется интернет и несколько десятков
МБ дополнительно. Во время загрузки можно продолжать читать. После загрузки
перевод работает офлайн; повторно скачиваются только отсутствующие модели.

Состав вариантов и проверка доставки описаны в `docs/DELIVERY.md`.

## Сборка

Нужны Python 3.10+, Java 21 и, для подписи, Android SDK Build Tools 35 или новее.
Работа проверена в Linux. Для Windows можно использовать WSL.

Проверка встроенных данных работает без сети:

```sh
python3 scripts/project.py validate
```

Сборка без подписи:

```sh
python3 scripts/project.py build --abi arm64-v8a --unsigned
```

При первом запуске скрипт скачивает закреплённые версии исходного APK и Apktool
и проверяет SHA-256. Из APK копируются неизменённые сторонние DEX и native-библиотеки.
Они исключены из архива исходников, но доступны по закреплённому адресу и уже
восстановлены в текущей облачной среде.

Можно указать существующие файлы вместо скачивания:

```sh
python3 scripts/project.py build --unsigned \
  --abi arm64-v8a \
  --apk /path/to/GreekReadingApp.apk \
  --apktool /path/to/apktool_3.0.3.jar
```

Подписанная сборка с прежним ключом:

```sh
python3 scripts/project.py build-all \
  --sdk /path/to/android-sdk \
  --keystore /private/path/to/debug.keystore
```

Результат: четыре файла `dist/GreekReadingApp-0.1.6-<архитектура>.apk`,
`dist/manifest.json`, отчёты по вариантам и `dist/SHA256SUMS`.
Команда `build` собирает один вариант, по умолчанию ARM64; `build-all` — все четыре.
Проверки упаковки запускаются командой:

```sh
python3 -m unittest discover -s scripts -p test_abi_packaging.py -v
```

Настройки текущего выпуска — в `release.json`; сведения об исходном APK 0.1.4
сохраняются отдельно в `recovery.json`.
Ключ не входит в проект и не должен попадать в Git.
В текущей среде сохранился прежний ключ:
`/workspace/.greek-tools/android-user/debug.keystore`.
Его сертификат совпадает с исходным APK; скрипт проверяет совпадение после подписи.
Пароли прежнего отладочного ключа — стандартные Android; для другого значения
скрипт принимает `RECOVERY_STORE_PASS` и `RECOVERY_KEY_PASS` из окружения.

## Пределы восстановления

`reference/java` — результат декомпиляции, **не готовый к компиляции Java-проект**.
Шесть файлов содержат функции, которые JADX восстановил с ошибками;
они перечислены в `recovery.json`. Точные инструкции этих функций сохранены в smali.
Исходные Kotlin-файлы, комментарии, прежние тесты, сценарии подготовки книги
и история разработки не восстановлены.

Для правок книги, оформления и точечных исправлений можно использовать текущую
собираемую основу. Для обычной разработки в Android Studio нужно поэтапно
восстановить Kotlin/Compose по Java, метаданным и smali. Порядок и совместимые
контракты приведены в `docs/RECOVERY.md`.
